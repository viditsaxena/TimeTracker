# TimeTracker 1.3.0

I put the quick buttons where they belong: on the sessions you've already tracked.

Find a session and click **+5m**, **+10m**, **+15m**, or **+20m**. That one click adds time to the same session. No window to open. You can click again if you need more. The daily and weekly totals update right away.

If adding time would overlap another session or go into the future, you'll see a message on that row. You can still click a session to edit its time or category. **Add missed time** is still there when you need a new session, like for a call you forgot to track altogether.

Download **TimeTracker-v1.3.0-macOS-universal.zip** below, unzip it, and move **TimeTracker.app** to **Applications**. Quit the old app before replacing it. Your saved sessions will still be there.

You need macOS 14 or newer. The ZIP includes Apple Silicon and Intel versions. I've tested it on Apple Silicon, but not on an Intel Mac yet. Apple hasn't verified the app, so your Mac may stop you the first time you open it. If you trust the download, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. [Apple explains this here](https://support.apple.com/en-us/102445).

The **SHA256SUMS.txt** file below has a checksum for the download. [The README](https://github.com/viditsaxena/TimeTracker) has the full instructions.
