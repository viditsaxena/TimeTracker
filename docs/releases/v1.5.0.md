# TimeTracker 1.5.0

There's one place to add missed time now. Near the top of the window, use **−** and **+** to choose the minutes, then click **Add**. It starts at 5 minutes. The buttons on every past session are gone.

TimeTracker finds the latest open space today that fits. If a timer is running, it first tries to add the time immediately before that timer started. It won't double-count time you've already tracked, and it tells you where the new time went. You can still choose an exact time if you need to.

The start/stop shortcut is now **Option–T**. Option–Space no longer controls TimeTracker.

Download **TimeTracker-v1.5.0-macOS-universal.zip** below, unzip it, and move **TimeTracker.app** to **Applications**. Quit the old app before replacing it. Your saved sessions will still be there.

You need macOS 14 or newer. The ZIP includes Apple Silicon and Intel versions. I've tested it on Apple Silicon, but not on an Intel Mac yet. Apple hasn't verified the app, so your Mac may stop you the first time you open it. If you trust the download, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. [Apple explains this here](https://support.apple.com/en-us/102445).

The **SHA256SUMS.txt** file below has a checksum for the download. [The README](https://github.com/viditsaxena/TimeTracker) has the full instructions.
