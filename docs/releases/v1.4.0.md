# TimeTracker 1.4.0

The session list is less crowded now. Each session has a small **− 5 min +** control and one **Add** button. Use the minus and plus to choose the number of minutes, then click Add. It starts at 5 minutes and changes in 5-minute steps.

Add extends that same session and updates the totals right away. If it would overlap another session or go into the future, you'll see a message on the row. You can still click the session to edit its time or category. **Add missed time** is there when you need a new session instead.

Download **TimeTracker-v1.4.0-macOS-universal.zip** below, unzip it, and move **TimeTracker.app** to **Applications**. Quit the old app before replacing it. Your saved sessions will still be there.

You need macOS 14 or newer. The ZIP includes Apple Silicon and Intel versions. I've tested it on Apple Silicon, but not on an Intel Mac yet. Apple hasn't verified the app, so your Mac may stop you the first time you open it. If you trust the download, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. [Apple explains this here](https://support.apple.com/en-us/102445).

The **SHA256SUMS.txt** file below has a checksum for the download. [The README](https://github.com/viditsaxena/TimeTracker) has the full instructions.
