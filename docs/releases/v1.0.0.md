# TimeTracker 1.0.0

A small Mac menu-bar timer for separating Work and Music time.

## Download and install

1. Download **TimeTracker-v1.0.0-macOS-universal.zip** below. The source-code archives are for developers.
2. Unzip it and drag **TimeTracker.app** to **Applications**.
3. Open the app. Press **Option–Space** to start or stop a timer from any app.

Requires **macOS 14 Sonoma or later**. This download includes Apple Silicon and Intel binaries. It was tested on an Apple Silicon Mac; the Intel binary was cross-compiled and has not been tested on Intel hardware.

This release is ad-hoc signed, not Apple Developer ID signed or notarized. macOS may block the first launch. If you trust this download, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. See [Apple’s instructions](https://support.apple.com/en-us/102445). Managed Macs may restrict this exception.

## Included

- Every new timer starts as Work; choose Music from the menu-bar menu while tracking to switch immediately.
- Compact menu bar: a timer icon when paused; elapsed time with a briefcase or music note while tracking.
- Separate daily and weekly totals, paired Work/Music bars, and session history.
- CSV export with categories and UTC timestamps.
- Local storage, automatic stop on sleep, and checkpoint recovery after an unexpected exit.
- No account, network connection, or Accessibility permission required.

If Option–Space is already assigned to Spotlight or another app, disable that assignment first. Closing the dashboard keeps the timer available; quitting the app stops it. Automatic launch at login is optional and can be configured in macOS Login Items.

Session data stays in `~/Library/Application Support/TimeTracker/sessions.json`. No session data is included in this download. Quit TimeTracker before installing an update; replacing the app preserves saved sessions.

SHA-256 checksums are provided in **SHA256SUMS.txt**. This first release does not include custom projects, manual session editing, idle detection, syncing, or automatic updates.
