# TimeTracker 1.0.0

I wanted one key to start a timer and the same key to stop it. Work and music each get their own total, so one doesn't get mixed into the other.

## Install it

1. Download **TimeTracker-v1.0.0-macOS-universal.zip** below. The source code ZIPs are for building the app yourself.
2. Unzip it and move **TimeTracker.app** to **Applications**.
3. Open it. Press **Option–Space** to start or stop tracking from anywhere on your Mac.

You need **macOS 14 or newer**. The download has both Apple Silicon and Intel versions. I've tested it on Apple Silicon, but not on an Intel Mac yet.

Apple hasn't verified this app, so your Mac may stop you the first time you open it. If you trust the download, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. [Apple explains how](https://support.apple.com/en-us/102445). A work or school Mac may not allow this.

If Option–Space opens Spotlight, turn that shortcut off in **System Settings → Keyboard → Keyboard Shortcuts → Spotlight**. You can also start and stop the timer with the button in the app.

## How it works

Each new timer starts as Work. To switch to Music while the timer is running, click the menu-bar timer and choose **Music**. TimeTracker saves the Work time and keeps going as Music. The next new timer starts as Work again.

The menu bar shows a timer icon when you're stopped. When you're tracking, it shows the time with a briefcase for Work or a music note for Music. The window shows separate daily and weekly totals, two bars per day, and a list of sessions. You can export them as a CSV file; its dates and times use UTC.

Closing the window leaves the timer available in the menu bar. Quitting the app or putting your Mac to sleep stops it. If the app closes unexpectedly, it recovers time through its last save, which happens about every 30 seconds.

Your sessions stay on your Mac in `~/Library/Application Support/TimeTracker/sessions.json`. No account or internet connection is needed, and this download contains no session data. Quit TimeTracker before installing a new version. Your saved sessions will still be there afterward.

The **SHA256SUMS.txt** file below has a checksum for the download. This version doesn't yet let you add more categories, edit old sessions, sync between Macs, or get automatic updates. [More details are in the README](https://github.com/viditsaxena/TimeTracker).
