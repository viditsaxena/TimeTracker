# TimeTracker 1.8.0

You can track standing now. Click **Stand up** in the window or menu bar menu, then **Sit down** when you're done. Standing has its own timer. It can run at the same time as Work or Music, and it won't change those totals.

The window shows standing time for today, this week, and each day in the weekly view. If you forget to sit down, click a standing block to fix its time. You can delete one there too. Standing blocks are included in the CSV export.

Download **TimeTracker-v1.8.0-macOS-universal.zip** below, unzip it, and move **TimeTracker.app** to **Applications**. Quit the old app before replacing it. Your saved sessions will still be there.

You need macOS 14 or newer. The ZIP includes Apple Silicon and Intel versions. I've tested it on Apple Silicon, but not on an Intel Mac yet. Apple hasn't verified the app, so your Mac may stop you the first time you open it. If you trust the download, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. [Apple explains this here](https://support.apple.com/en-us/102445).

The **SHA256SUMS.txt** file below has a checksum for the download. [The README](https://github.com/viditsaxena/TimeTracker) has the full instructions.
